Como funciona (documentação)

1. O que o seu sistema recebe

Um POST com Content-Type: application/json no endereço colado acima. O corpo traz todos os campos da ficha. Com os dados da ficha atual, fica assim:


                            
2. Campos

                            
Use os nomes abaixo para pegar cada informação do seu lado. Os valores são sempre texto: marcações vêm como "Sim" ou "Não", a data como AAAA-MM-DD e campo em branco como "". O que vai é o que está na ficha na hora do envio, já com as edições do técnico.

                            
Campo no JSONNa fichaValor agora

                            
3. Quando dá para enviar

                            
Igual à impressão: só depois de concluir todos os testes e preencher o nome do técnico. Use "Pré-visualizar" para conferir o que será enviado sem enviar nada.

                            
4. Liberar o site no seu servidor (CORS)

                            
O envio sai do navegador, então o seu servidor precisa autorizar o ycodex.xyz. Ele deve responder à requisição OPTIONS e ao POST com:

                            
Access-Control-Allow-Origin: https://ycodex.xyz
Access-Control-Allow-Methods: POST, OPTIONS
Access-Control-Allow-Headers: Content-Type

                            
Sem essa liberação, o navegador bloqueia o envio e aparece um erro de rede aqui. Se o seu sistema pede uma chave de acesso, coloque-a no próprio endereço, por exemplo https://seu-sistema.com.br/webhook?chave=SUA_CHAVE. Dica: salve o endereço completo no app Senhas do celular (iCloud Keychain). Na próxima vez, basta tocar no campo e o sistema preenche automaticamente.
